Information and Communication Technology Class Program

Introduction

The ICT Program is designed to help students understand the basic concepts of information and communication technology. Through this program, students will learn how technology is used in daily life, education, and the workplace.

Students will also develop practical skills in website development and database management. This program prepares students to think creatively, solve problems, and build simple digital projects.

Learning Topics

  • HTML
  • CSS
  • JavaScript
  • PHP
  • MySQL

Learning Roadmap

  1. Learn HTML
  2. Learn CSS
  3. Learn JavaScript
  4. Learn PHP
  5. Learn MySQL

Technology Definitions

HTML
HTML is used to create the structure and content of a webpage.
CSS
CSS is used to style and design the appearance of a webpage.
JavaScript
JavaScript is used to make a webpage interactive and dynamic.
